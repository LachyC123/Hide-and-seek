Phones can only see each other through something on the internet. A free Supabase project is enough, and you only do this once — after that the join link carries the connection, so nobody else has to set anything up.

Step 1 — make a project

Go to supabase.com, sign in with GitHub and make a new project. Any name, any region near you. It takes a minute or two to finish building. The free plan is plenty.

Step 2 — make the tables

In your project, click SQL Editor in the left sidebar, then New query. Press the button below, paste into the big empty box, and hit Run. You should see “Success. No rows returned” — that is what success looks like here.


      
If the button will not copy on your
      phone, open supabase.sql in the game’s GitHub repo on a laptop and copy it there.

    


    

      
Step 3 — copy your two values

      
Left sidebar → Project Settings → API.
      You need the Project URL, and the key labelled anon / public (newer
      projects may call it publishable). Paste both below.

      
Not the one marked
      service_role or secret. That one is a master key — it must never go in a game
      or a link. If you paste it by mistake, reset it in Supabase.

Play safe

    

      
• Play only in safe, public, permitted places.

      
• Never trespass. Never play near traffic you can't cross safely.

      
• Obey roads and crossings. Look up, not down.

      
• Never play while driving.

      
• Never enter somewhere dangerous just to stay in the zone. Being exposed is better than being hurt.

      
• The host picks the play area and is responsible for it.
